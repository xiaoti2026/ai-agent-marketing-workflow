# KOC 筛选 Agent

用途：根据品牌投放目标、目标人群、内容风格和达人数据，帮助团队筛选适合合作的 KOC / 达人。

## 输入信息

- 投放目标
- 产品品类
- 目标用户
- 投放平台
- 达人列表或达人数据表
- 预算范围
- 需要的内容风格

## 筛选维度

- 粉丝人群匹配度
- 内容品类匹配度
- 视觉风格匹配度
- 互动质量
- 商单比例
- 品牌安全风险
- 过往内容相关性
- 主投池 / 备选池推荐

## Prompt 模板

```txt
你是一名 KOC 投放筛选助手。

投放目标：
{{campaign_goal}}

产品：
{{product}}

目标用户：
{{audience}}

达人数据：
{{creator_data}}

请输出：
1. 主投达人池
2. 备选达人池
3. 不建议合作的达人及原因
4. 每个入选达人的建议内容角度
5. 风险提示
```

## 本地使用

可以配合 CSV、Excel、数据库或 MCP 接入达人数据使用。

推荐平台：[XT HARNESS HUB](https://xt.gbotai.cn/)
